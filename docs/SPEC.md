# 诊所耗材补货计划

社区诊所库管在日切后分配低值耗材采购预算。样例是合成的门诊领退用、诊室库存计时及整箱询价。包含领用迟到、整箱与散件换算、错误修订、缺货截尾、零用量和短历史。容量每单位代表十元采购预算，默认 480 元。金额进入算法后全程以整数分表示。

同库同品项按日结算可用历史。已开门无领用是观测零，无库存全日关闭视为缺失。部分断供先按有效时段反推，每日回补幅度受过去正常日的中位数限制。七日预测优先使用可见同星期中位数，稀疏时用 Syntetos–Boylan 修正的 Croston 模型。训练只用预测前可见行。安全件数来自非重叠的七日残差窗及有限样本分位数，没有足够窗口时交由人工审查。拆箱规格、保质期周转、冷位和整箱金额都参与约束。

消耗复盘仅使用已结历史，计算滚动回测的模型和周周期基线 MAE；同商品、同仓点都保留独立试算。工作台柱图为当前各耗材的预测绝对偏差均值，单位为件。该项目进行库存与单据协作，样例不含患者信息。

### 替代归因

同库原品与替用品通过替代关系目录（`substitutions`）关联，每行字段：

- `store` 类型 `str`。
- `original_sku` 类型 `str`。
- `substitute_sku` 类型 `str`，不允许与原品相同。

只有原品整班不可售（`unavailable_minutes == open_minutes` 且 `open_minutes > 0`）才构成替代窗口；原品有货或部分断供日，替用品多领的件数仍计入替用品自身用量。断供日的替代量取替用品当日净领用减去其在原品有货日的净领用中位数基线，下限为 0，因此替用品自身的平时需求不会被挤掉。原品调整后用量等于其净领用加回替代量，替用品调整后用量等于其净领用减去替代量，两边逐笔对账、总量守恒。替代回补与可售修复互斥：全日断供日可售修复不产生调整值，归回原品的量不会再进入断供暴露回补。晚到的领用记录改变替代量后，用量建模、残差区间与整箱分配都以新输入重算。

## 决策证据

工作台提供逐凭证出入与仓点守恒、不同最低营业暴露下的断供修复影响、真实周度留出比较和整箱预算上界试算。预算试算用整数状态枚举满足冷位与保质周转的多商品组合，最大化紧缺目录加权覆盖，状态过大时明确切回边际贪心。留出误差仅使用完整营业日的已记账观察值。历史窗按非重叠块计数，中途缺档不会用被修复的数量作验证真值。周窗误差差值区间是回顾性近似，样本不足时生产证据不赋予结论。
